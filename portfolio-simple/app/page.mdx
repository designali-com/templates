## Features

This website is built as a flexible, developer-friendly platform with a focus on performance, customization, and content.

* **Syntax highlighting** — Read code examples with clean syntax highlighting.
* **Light / dark mode** — Switch between light and dark themes.
* **Sitemap support** — Automatically generate a sitemap for better discoverability.
* **Fully customizable** — Customize the layout, typography, colors, components, and content.
* **Optional redirects** — Configure redirects when pages or URLs change.
* **Markdown / MDX** — Write content using Markdown and extend it with React components.
* **Responsive design** — Optimized for desktop, tablet, and mobile experiences.
* **Reusable components** — Build pages using modular and reusable UI components.
* **SEO ready** — Structured metadata and semantic content for better search visibility.
* **Fast by default** — Built with modern Next.js features for a fast and scalable experience.
