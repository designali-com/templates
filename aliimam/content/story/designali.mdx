# Where thoughtful design meets production-ready code

**designali** is my studio and my longest-running project. It is a design and development practice, an open component library, a template shop and a playground, all in one place.

It started because I kept making the same things again and again for clients: heroes, pricing sections, logo walls, icon sets. At some point I asked a simple question:

> **What if I designed it once, built it properly, and shared it with everyone?**

## The beginning: Dalim

Before designali there was **Dalim**, a collection of small, scrappy sites I built while teaching myself to code:

- **Dalim UI:** my first attempt at a component library
- **Dalim Icons and Dalim Fonts:** asset collections for designers
- **Dalim Visuals and Dalim Graphic:** galleries of my visual and graphic work
- **Dalim Works and Dalim Agency:** early portfolio and studio sites
- **Dalim Tools:** small utilities I needed myself

None of them were perfect. But each one taught me something new about React, Next.js, deployment, or simply finishing a project. They are all still live, a record of how I learned.

Over time those separate experiments needed one home, one brand and one system. That became **designali**.

## What designali is today

### Components

Animated, reusable UI pieces like **Bento, Counter Number, Dot Pattern, Grid Pattern, Gauge, Marquee, Typewriter** and more, built with React, Tailwind CSS and Motion.

### Blocks

Ready-made page sections: **Hero, Header, Footer, Feature, Pricing, Clients, Testimonials, FAQs, Call to Action, Gallery, Contact, Authentication, Forms, Analytics, Blog, Portfolio, Ecommerce** and more.

Every block installs with a single command through the shadcn CLI:

```bash
npx shadcn add @designali/hero-1
```

### Templates

Full sites you can launch and customise: **Ali Imam**, **Portfolio Simple**, **Design Agency** and **Vercel**, with more like **FinAI**, **Payora** and **Resort** in progress.

### Icons, logos and vectors

Icon sets, brand logos and a large vector collection, with SVGs you can copy or download. The logos also ship as an npm package, `@aliimam/logos`.

### Fonts

**[Designali Mono](/story/designali-mono)**, a free, open-source monospace font for design and code, with 8 weights, a variable font, webfonts and a Term build for terminals.

### Tools

**[CopyCode](/story/copycode)**, a Chrome extension that copies any block on a web page as Next.js + shadcn/ui TSX, HTML, SVG or an image, ready for your editor, Figma or Paper.

### Studio work

Alongside open-source work, designali takes on client projects across art direction, motion design, web development and AI-assisted workflows, for brands and agencies that want design and engineering under one roof.

## How it's built

designali runs as a **monorepo** with Turborepo and pnpm:

- `apps/web`: the main site, registry and docs
- `apps/ui`, `apps/design` and `apps/www`: supporting apps and experiments
- `templates/*`: each template as its own Next.js app
- `tools/copycode`: the CopyCode Chrome extension
- `packages/*`: shared UI and config

The stack is **Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Base UI, Fumadocs** and **Vercel**. Design happens in **Figma** and **Paper**, and a lot of the iteration now happens with **Claude** and **Cursor** at my side.

## My approach

### 01. Understand

Start with the real problem: who is this for, and what do they need to ship?

### 02. Design

Typography, spacing and hierarchy come first. Decoration comes last.

### 03. Systemise

Turn good one-off decisions into tokens, components and patterns.

### 04. Build

Take it into code myself, so nothing gets lost in hand-off.

### 05. Share

Document it, publish it, and let people use it.

## What I care about

- **Clarity:** design should communicate before it decorates.
- **Craft:** small details like spacing, motion and empty states make the biggest difference.
- **Accessibility and performance:** beautiful should also mean usable and fast.
- **Openness:** good design should be accessible, not locked away.
